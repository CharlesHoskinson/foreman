# ForeDi credential manager and OpenBao operations

## Why

The reusable store exists, but Foreman cannot select it through its live resolver or manage it through the CLI.

## What Changes

- CM01: Explicit selection.
- CM02: Host management interface.
- CM03: Private import.
- CM04: Secret-free commands.
- CM05: Maintenance authority.
- CM06: Production deployment.
- CM07: Real-server qualification.
- CM08: Versioned lifecycle and stale-writer refusal.
- CM09: Provisioned OpenBao control authority.
- CM10: Evidence-bounded account or backend quarantine.
- CM11: First-import reservation and stale-writer fencing.
- CM12: Explicit reconciliation and clearance.
- CM13: Exact confirmation and current delivery authority.
- CM14: Pure executable PEL policy without authorization grants.

## Impact

This draft extends Return of the ForeDi release preparation. It does not accept the release or authorize live credential migration or publication.
Existing source and historical evidence remain intact. New executable code uses Node.js 24, strict TypeScript, and Effect.

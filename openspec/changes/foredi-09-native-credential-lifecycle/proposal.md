# ForeDi native credentials for AGY, Codex, Claude, and Grok

## Why

Storage identifiers do not establish native credential access, refresh ownership, or isolated worker delivery.

## What Changes

- NL01: Independent vendor qualification.
- NL02: Credential custody.
- NL03: Refresh serialization.
- NL04: Ambiguous refresh recovery.
- NL05: Identity continuity.
- NL06: Migration transaction.
- NL07: Revocation semantics.
- NL08: Readiness agreement.

## Impact

This draft extends Return of the ForeDi release preparation. It does not accept the release or authorize live credential migration or publication.
Existing source and historical evidence remain intact. New executable code uses Node.js 24, strict TypeScript, and Effect.

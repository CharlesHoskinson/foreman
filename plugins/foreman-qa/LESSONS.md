# LESSONS.md

Append-only register of what each Foreman release taught the foreman-qa
plugin. Entries are never edited or removed once recorded; a correction is a
new entry, not a rewrite. See `skills/foreman-qa-maintenance/SKILL.md` for
the ritual that produces these rows.

Columns: release, date, symptom, root cause, the rule that now prevents it,
and where that rule is written in the plugin.

| Release | Date | Symptom | Root Cause | Rule | Where |
|---|---|---|---|---|---|
| v0.2.9.0 | 2026-07-28 | An unanchored `violation` substring predicate matched `[ok] No violation found`, so a check classified clean and dirty output identically and stayed green for weeks. | The predicate tested for the word `violation` anywhere in the tool's output instead of anchoring on the tool's actual failure marker, so the tool's own success message satisfied it. | Every predicate carries a positive control proving it discriminates. | `skills/foreman-qa-maintenance/SKILL.md`, ritual step 2 |
| v0.3.0 (pending) | 2026-08-06 | A launcher re-exec dropped the parent's node flags, so a PID-namespace child could not resolve its own modules. It failed only where `unshare` was permitted and passed where it was denied, which is why CI never caught it. | The re-exec path rebuilt the child's argv without carrying forward the loader flags the parent had been started with, and the only host class that exercises the `unshare` path is not the one CI runs on. | CI green only proves the paths CI took. | `skills/foreman-qa-maintenance/SKILL.md`, ritual step 1 |
| v0.2.9.0 | 2026-08-07 | A commit captured pre-edit files because `git add` ran before a late fix. | The fix landed after staging, so the index still held the pre-fix blob; the commit was cut from the index, not from the working tree, and nothing re-diffed the two. | A commit records the INDEX; re-add after any late edit and confirm `git status --porcelain` is empty. | `skills/foreman-qa-maintenance/SKILL.md`, ritual step 3 |
| v0.2.9.0 | 2026-08-07 | A scripted edit opened a tracked file for writing and truncated it when the write failed. | The script opened the destination path directly in write/truncate mode before it had produced valid output, so a failure between open and successful write left a zero-byte or partial file in place of the original. | Write to a temp file, assert on it, then move it into place. | `scripts/plugin-lessons.sh` (this script performs no direct writes to tracked files) |
| v0.3.0 (pending) | 2026-08-07 | This plugin's own staleness check reported `check clean` after an advertised skill was deleted. | It parsed `plugin.json` for a `skills` key that does not exist, because Claude Code discovers skills by directory. The loop iterated an empty list, found nothing to report, and returned success. | A pass over an empty selection is not coverage. Fail closed on zero items and print the selection size beside the verdict. | `scripts/plugin-lessons.sh`, run_check disk-truth pass |
| v0.3.0 (pending) | 2026-08-07 | A slice reported `skip=4` for a file that contains 12 tests, and the figure was quoted as a host characteristic. | The file hung and was killed at the 600s per-file timeout after four skips had been recorded. The counts described when it died, not what the file does. | Never quote a TIMEOUT slice's counts, and never lower a baseline to match one. Fix the hang or install the dependency, then re-measure. | `skills/foreman-testing/references/gate-and-ratchets.md` |
| v0.3.0 (pending) | 2026-08-07 | A reference page documented the package layout correctly and would have been wrong the day it merged. | It named the only workspace that existed at the time, while a change already in flight added a second one at the repository root. | Check a documentation claim against changes in flight, not only against the current tree. | v0.3.0 (pending) | 2026-08-07 | The evidence doctrine shipped two figures that no command in the repository could reproduce. | They came from a measurement made in conversation and were passed to the writing lane as given. Record the command beside the number, and state a generalisation's sample size. | `skills/foreman-qa/references/measurements.md` |
| v0.3.0 (pending) | 2026-08-07 | Arming the test gate silently changed `tools/ci-local.sh` from mode 100755 to 100644, which would have failed CI with a permission error. | The edit used write-to-temp-then-replace, which is the correct and recommended shape, but `os.replace` carries the TEMP file's mode onto the destination and a temp created by `io.open` is 0644. The safe pattern caused the regression. | Copy the destination's mode onto the temp before replacing, and read the `old mode`/`new mode` lines in `git diff` before committing. Confirm with `git ls-files -s`, since the INDEX is what CI reads. | `skills/foreman-code-quality/references/shell-conventions.md` |
| v0.3.0 (pending) | 2026-08-07 | Three files were edited to arm the test gate, but `git diff` listed only two, and a commit at that moment would have armed CI while leaving `tests/run.sh` on shadow -- a gate that reads as armed and is not. | `git update-index --chmod=+x` staged one file's CONTENT as well as its mode, so the index and the working tree disagreed about which edits existed. `git diff` shows unstaged changes only, so the staged file vanished from it. | Compare the number of files in the diff against the number you edited. Inspect the index directly with `git show :path` and `git status --porcelain`, where a leading column means staged and a trailing column means unstaged. | `commands/foreman-qa-preflight.md`, steps 1 and 4 |
| v0.3.0 (pending) | 2026-08-07 | An inherited claim that `lane-queue.bats` was 14 pass / 7 fail / 2 skip was measured, found to be 21 / 0 / 2, recorded as FALSE, and that refutation propagated into this plugin, an operating prompt, and two commit messages. The refutation was run on `main`, which lacks that port. Both measurements were correct; they described different trees. | A figure carries a TREE as well as a command. Before refuting an inherited claim, establish which ref it was made on -- a claim about unmerged code cannot be tested on the branch that lacks it. | `skills/foreman-qa/references/measurements.md`, "A figure carries a tree" |
| v0.3.0 (pending) | 2026-08-07 | An unattended overnight run delivered about four hours of work in seven and a half, with close to three hours idle. | An hourly cron backstop was treated as the work schedule. Gate runs were also treated as blocking when they run in the background and two other worktrees were free. | A backstop is for session death, never a schedule. Never end a turn on a completed unit when the next action is known. A running gate blocks one tree, not the session. | `skills/foreman-afk/SKILL.md` |
| v0.3.0 (pending) | 2026-08-07 | GitHub's documented branch-rename endpoint closed open PR #27 instead of retargeting it, twice, from two different actors, the second time from a corrected instruction. | The endpoint deletes the old ref and closes any PR whose head pointed at it as an undocumented side effect; a corrected instruction that specifically cited the documented endpoint was wrong the same way. | A documented API call is an unexecuted claim about its behavior, not evidence. Verify against a disposable target before it runs against the record that matters. | `skills/foreman-qa/references/evidence-rules.md`, "An authority citation is not verified behavior"; `skills/foreman-qa/references/failure-catalogue.md` |

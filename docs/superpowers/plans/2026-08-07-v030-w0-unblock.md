# v0.3.0 W0 — Unblock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` (recommended) or
> `superpowers:executing-plans` to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the test gate trustworthy on all three platforms, clear the
release branch's 27-commit drift from `main`, and freeze `main` — so that every
later v0.3.0 workstream starts from a green, current, single-trunk baseline.

**Architecture:** `tests/baseline.tsv` is keyed by file alone while
`tests/skip-budget.tsv` is keyed by file and platform. One expected-pass number
therefore has to hold for linux, windows and wsl at once, which is impossible
for any test whose pass count depends on a host capability. Task 1 removes that
asymmetry by giving the baseline the same three-column shape, and derives the
new table from three real runs rather than from any one host. The remaining
tasks move the trunk to the release branch and diagnose the two failures whose
causes are not yet known.

**Tech Stack:** Bash, Bats, awk, GitHub Actions, `gh` CLI.

## Global Constraints

Every task's requirements implicitly include this section.

- Work happens in WSL at `/root/foreman`, on ext4. A `/mnt/c/...` checkout has
  previously left the installed plugin resolving to zero files.
- Do not de-track `skills/foreman/runtime/dist/`. Those 16 bundles are the
  shipping artifact, digest-bound by `skills/foreman/runtime/manifest.json`.
- An unrunnable gate counts as a failure, never as a pass.
- No measurement is quoted without the command that produced it.
- No gate ships that cannot fail: every new or changed gate gets a positive
  control row in `tests/positive-control-registry.tsv`.
- Markdown must pass `npx --no-install markdownlint-cli2 <file>` and
  `codespell --config .codespellrc <file>`.
- Commits carry no AI attribution and no `Co-Authored-By` trailer.
- Adding a `.bats` file under `tests/` requires a row in **both**
  `tests/baseline.tsv` and `tests/skip-budget.tsv`, or `tests/run.sh` exits 2.

```bash
#!/usr/bin/env bats

setup() {
  REPO_ROOT="$(cd "$BATS_TEST_DIRNAME/.." && pwd)"
  load "$REPO_ROOT/tests/lib/preconditions.bash"
  PLATFORM="$(preconditions_platform)"
  WORK="$(mktemp -d "${TMPDIR:-/tmp}/policy-test.XXXXXX")"
  FIXTURE="tests/fixtures/policy/trivial.bats"
}

teardown() {
  rm -rf -- "$WORK"
}

@test "baseline header without a platform column is rejected" {
  printf 'file\texpected_passes\n%s\t1\n' "$FIXTURE" >"$WORK/baseline.tsv"
  printf 'file\tplatform\tpermitted_skips\n%s\t%s\t0\n' \
    "$FIXTURE" "$PLATFORM" >"$WORK/skip.tsv"

  run env TEST_BASELINE_FILE="$WORK/baseline.tsv" \
    TEST_SKIP_BUDGET_FILE="$WORK/skip.tsv" \
    TEST_SLICE_REPORT="$WORK/slices.tsv" \
    bash "$REPO_ROOT/tests/run.sh" "$REPO_ROOT/$FIXTURE"

  [ "$status" -eq 2 ]
  [[ "$output" == *"baseline header must be: file<TAB>platform<TAB>expected_passes"* ]]
}

@test "baseline lookup selects the row for the current platform" {
  {
    printf 'file\tplatform\texpected_passes\n'
    printf '%s\tlinux\t1\n' "$FIXTURE"
    printf '%s\twsl\t1\n' "$FIXTURE"
    printf '%s\twindows\t1\n' "$FIXTURE"
  } >"$WORK/baseline.tsv"
  {
    printf 'file\tplatform\tpermitted_skips\n'
    printf '%s\tlinux\t0\n' "$FIXTURE"
    printf '%s\twsl\t0\n' "$FIXTURE"
    printf '%s\twindows\t0\n' "$FIXTURE"
  } >"$WORK/skip.tsv"

  run env TEST_BASELINE_FILE="$WORK/baseline.tsv" \
    TEST_SKIP_BUDGET_FILE="$WORK/skip.tsv" \
    TEST_SLICE_REPORT="$WORK/slices.tsv" \
    bash "$REPO_ROOT/tests/run.sh" "$REPO_ROOT/$FIXTURE"

  [ "$status" -eq 0 ]
  [[ "$output" == *"baseline_verdict=PASS"* ]]
}

@test "a platform absent from the baseline is an actionable error" {
  {
    printf 'file\tplatform\texpected_passes\n'
    printf '%s\tnosuchplatform\t1\n' "$FIXTURE"
  } >"$WORK/baseline.tsv"
  {
    printf 'file\tplatform\tpermitted_skips\n'
    printf '%s\t%s\t0\n' "$FIXTURE" "$PLATFORM"
  } >"$WORK/skip.tsv"

  run env TEST_BASELINE_FILE="$WORK/baseline.tsv" \
    TEST_SKIP_BUDGET_FILE="$WORK/skip.tsv" \
    TEST_SLICE_REPORT="$WORK/slices.tsv" \
    bash "$REPO_ROOT/tests/run.sh" "$REPO_ROOT/$FIXTURE"

  [ "$status" -ne 0 ]
  [[ "$output" == *"missing pass baseline for $FIXTURE on $PLATFORM"* ]]
}
```

Replace `lookup_baseline` in full:

```bash
# @description Look up one exact file-and-platform pass baseline.
# @arg $1 repository-relative slice key
# @arg $2 platform id
# @set POLICY_VALUE expected pass count on success
# @set POLICY_ERROR actionable error on failure
lookup_baseline() {
  local key="$1" platform="$2"
  local -a matches=()
  POLICY_VALUE=""
  POLICY_ERROR=""
  mapfile -t matches < <(
    awk -F '\t' -v key="$key" -v platform="$platform" '
      NR > 1 {
        sub(/\r$/, "", $NF)
        if ($1 == key && $2 == platform) print $3
      }
    ' "$BASELINE_FILE"
  )
  if (( ${#matches[@]} == 0 )); then
    POLICY_ERROR="missing pass baseline for $key on $platform"
    return 1
  fi
  if (( ${#matches[@]} != 1 )); then
    POLICY_ERROR="duplicate pass baseline for $key on $platform"
    return 1
  fi
  if [[ ! "${matches[0]}" =~ ^[0-9]+$ ]]; then
    POLICY_ERROR="invalid pass baseline for $key on $platform: ${matches[0]}"
    return 1
  fi
  POLICY_VALUE="${matches[0]}"
}
```

At the call site (`if lookup_baseline "$key"; then`), pass the platform:

```bash
  if lookup_baseline "$key" "$platform"; then
```

Then build the table — column 1 is the slice key, column 3 is the observed

`tests/test-policy.bats` is deliberately **excluded** from the derivation and
appended by hand: the linux and windows artifacts predate it, so deriving it
would produce a wsl row only and leave the slice with one row instead of three.

```bash
cd /root/foreman
NEW=tests/test-policy.bats
{
  printf 'file\tplatform\texpected_passes\n'
  {
    for p in linux wsl windows; do
      case "$p" in
        linux)   src=/tmp/baseline-src/linux/_temp/foreman-test-slices.tsv ;;
        windows) src=/tmp/baseline-src/windows/_temp/foreman-test-slices.tsv ;;
        wsl)     src=/tmp/baseline-src/wsl-slices.tsv ;;
      esac
      awk -F '\t' -v p="$p" -v skip="$NEW" \
        'NR>1 && $1 != skip {print $1"\t"p"\t"$3}' "$src"
    done
    printf '%s\tlinux\t3\n%s\twsl\t3\n%s\twindows\t3\n' "$NEW" "$NEW" "$NEW"
  } | LC_ALL=C sort -t $'\t' -k1,1 -k2,2
} > tests/baseline.tsv
```

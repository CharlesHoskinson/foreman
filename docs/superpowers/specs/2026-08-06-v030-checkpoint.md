# v0.3.0 simplification — implementation checkpoint, 2026-08-06

This is a **stopping point, not a conclusion**. Design was agreed through Section 1 of 3 and
then paused. Nothing here is approved for implementation. Read this file, then
`docs/research/2026-08-06-testing-council/` for the evidence behind it.

Status: **draft, pending review.** The brainstorming flow (design → spec → user review →
plan) stopped after Section 1.

## 1. Decisions taken (these are settled)

| Decision | Choice | Why |
|---|---|---|
| Release thesis | **The Node migration is finished** — one runtime, one language | Provable with a single command, unlike the 18-sprint program |
| Scope boundary | **Foreman's own Python + the broken lane-queue port.** Vendored plugins declared, not rewritten | 14 tracked `.py`, only 7 are Foreman's |
| Session port | **Shrink the surface first, then port** | Porting code nothing calls is the busywork being cut |
| TDD regime | **Full mechanical regime, repo-wide** | Owner's call, made with the size stated |
| Sequencing | **A — regime first, migration written under it** | A retrofit deferred to "the end" is the first casualty of a deadline |
| Retrofit exit condition | **Every finding fixed *or declared*** — not "zero findings" | Otherwise a mutation pass over 1360 tests becomes its own 800-task program |

The release then proves: `git ls-files '*.py'` lists only vendored and archived files,
`gates-linux` is green, and `session.bats` passes against the TypeScript with the Python deleted.

## 2. Audit findings that drove those decisions

- The v0.3.0 program is **43 packages, ~819 open tasks, 18 sprints**. Over half of it is the
  tool observing itself: ~310 tasks of knowledge/graph plane (including **87 tasks to decide
  whether the graph plane was worth building**), 41 for doctrine-drift detection, 47 for
  decision lineage, 51 for test-infrastructure hardening.
- **The session store's real surface is four tables** — `facts` 510, `measurements` 136,
  `obligations` 103, `sessions` 10, across 10 recorded sessions. The schema defines exactly
  those plus `schema_meta`.
- **There is no `projects` table.** Sprint 6's "project registry, multi-project recovery,
  deleted-project behaviour" would build a subsystem that has never existed and never held a
  row. Cut.
- **`fm-session.py project` emits TerminusDB documents**, and TerminusDB is withdrawn — three
  archived change packages say so. Zero rows, no callers, dead integration. **Retire it.**
- **Nothing in the automation invokes `fm-session.py`.** Every executable reference is its own
  argparse, except `tests/session.bats`. It is driven by humans and agents following
  `CLAUDE.md` / `RESUME.md`.
- **`session.bats` has zero output-content assertions** — 34 tests, 44 exit-status checks, 20
  sqlite probes, 42 sidecar probes, and it never asserts what a command *prints*. A TypeScript
  port could emit entirely different stdout and pass. **Golden fixtures are required before the
  Python is deleted.**

## 4. Suite accountability — the structural finding

Eight independent lenses converged here. Every defect found this week lived in this blind spot.

- `npm test`'s globs are **unquoted**; `sh` has no globstar, so `src/**/*.test.ts` is read as
  `src/*/*.test.ts`. It works *by accident* — nothing lives in a `src/` subdirectory yet. The
  first test file added under one silently drops that package's other 36 files.
- **`node --test` exits 0 when a glob selects zero tests**, so that drop stays green.
- **168 bare `if (…) return;`** statements in TS test bodies. Node counts them as passes.
  Several are real capability guards.
- **4 of 5 skips are anonymous** — `{ skip: true }` prints a bare `# SKIP`; `{ skip: "reason" }`
  prints the reason. The codebase uses the boolean form.
- **`tests/baseline.tsv` claims 21 passes for lane-queue; reality is 14 pass / 2 skip / 7 fail.**
  `tests/run.sh` defaults `TEST_GATE_MODE=shadow`. The instruments exist and are pointed at a
  disarmed trigger. Recorded in the session store as fact id 34.
- The four files `test-infrastructure-hardening` specifies to prevent exactly this
  (`positive-control-registry.tsv`, `check-inventory.sh`, `positive-control.bash`,
  `inject-regressions.sh`) **were never written**.

## 5. Effect adoption gap

Effect is used for structure and almost none of its concurrency primitives. Verified by grep,
repo-wide:

`Effect.timeout` **0** · `Effect.retry`/`Schedule` **0** · `Effect.makeSemaphore` **0** ·
`Effect.uninterruptible` **0** · `TestClock` **0** · `Effect.all` **1**, unconcurrent · only
`Effect.fork` used, four call sites in one file.

Every timeout and retry is hand-built, including a bespoke `LauncherClock` reimplementing
Effect's own `Clock`, and an 8-way child-process race via raw `Promise.all` + `Atomics.wait`
entirely outside Effect. `supervise.test.ts` hand-rolls a 5ms-capped fake clock over real
`setTimeout` to compensate for the absent `TestClock` — strictly worse than the documented
pattern.

Confirmed idiomatic and **not** to be changed: `files-only.ts` throwing internally and
converting at the Effect boundary via `Effect.try`/`Effect.either`. Two lenses said so
independently, unprompted.

## 6. Corrections made during the session

1. **The `lane-queue` cause.** Recorded in commit `f30a39e` and PR #29 as "the Node
   implementation does not yet reproduce the POSIX quoting dialect, the `shell_command`
   override classification, or the `FORCE_MISSING` fallback." **Wrong** — inferred from test
   names. The `add` verb gained five mandatory Endstop flags; the behaviour was ported *and
   extended*, and five artifacts now encode two contracts (`SKILL.md` new, shipped CLI new and
   enforcing, `queue-admission.ts:639` old and printing the wrong syntax, `docs/USAGE.md` old,
   `tests/lane-queue.bats` old). PR #29's body carries a dated correction. The commit message
   stands as recorded history. Logged in `bugeventlog.md`.
2. **`fast-check` is not installed where property tests would go.** Declared only in
   `components/council`; the `node_modules` copy is `3.23.2`, a transitive of `effect`. A
   property test written today would silently bind to an undeclared, major-behind version.
   Caught independently by two lenses after I asserted otherwise in their briefs.

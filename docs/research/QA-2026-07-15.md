## Best practices distilled

### Claude Code (Anthropic)

- Custom subagents: YAML frontmatter + system prompt; clear **description** drives auto-delegation.
- Pin **model**, restrict **tools**, prefer read-only tools for reviewers.
- Use **`isolation: worktree`** for implementers that must not touch the main tree (hard-mode analog).
- Built-in Explore inherits session model (cost risk on Fable) — pin a cheap Explore override if needed.
- Skills load into sessions; agents can **preload skills**.
- Subagents do **not** share chat context — matches Foreman’s five-part spec contract.
- Advisor **API tool** ≠ our `foreman-advisor` agent; both are “commitment guidance,” different surface.

### Codex (OpenAI)

- Headless: `codex exec` with `--sandbox read-only|workspace-write`.
- Code review cookbook: **read-only sandbox + structured `--output-schema` + cold PR diff in prompt**.
- Native `codex review` / `codex exec review` with `--uncommitted` / `--base` / `--commit`.
- Do not let the reviewer hold write sandbox or credentials it can exfiltrate (CI isolation notes).

### Grok Build (xAI)

- Headless: `-p` / `--prompt-file`, `--cwd`, `--output-format plain|json|streaming-json`.
- Live CLI also supports `--permission-mode acceptEdits` (validated on this machine).
- Prefer headless one-shots for worker lanes; set working directory explicitly.
- `--no-auto-update` in automation (docs).

### Cross-cutting multi-agent

- Decorrelated review (different model family) beats same-family self-review.
- Never trust worker “tests passed”; orchestrator re-runs checks.
- Bounded rework loops; fail closed when audit infra missing.
- Schema-forced auditor JSON > free-form prose.

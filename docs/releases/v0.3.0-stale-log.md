## Cross-cutting root cause

Every item in sections A, B, and C is the same defect: **v0.2.9.0 shipped, and the documents
that gated it were never demoted from "current authority" to "historical record."** PR #27's
own "Why" says this in as many words — "Stale and fragmented project records made Council
reviews incomplete." The v0.3.0 program already allocates task 0.2 to it.

The reason it recurs is structural, and `RESUME.md` names it: status that lives in a hand-edited
file rots, status that lives in the session store does not. `checklist.md`, `ROADMAP.md`, and
`docs/RESIDUALS.md` are all hand-edited status files, and all three are currently wrong.
A cleanup that only fixes their contents will be stale again at v0.3.1.

## Product

Total Georgecall ships one installable Council preflight boundary.

The runtime uses Node.js 24 and TypeScript with Effect. It builds as one
self-contained ESM executable named `council-preflight`. It does not load
workspace TypeScript source at run time.

The eight Council packages are `schema`, `domain`, `application`,
`platform-node`, `runtime-node`, `adapter-grok`, `adapter-claude`, and
`adapter-codex`.

The executable:

- reads one bounded closed request from stdin
- writes one strict provider-neutral result to stdout
- compiles the Attempto Controlled English contract before a provider starts
- supports bounded canaries for Grok, Claude, and Codex
- fails closed for Google because Gemini is absent
- returns typed secret-safe failures for invalid input, provider failures,
  timeouts, output limits, and unsupported Google dispatch

ACE Profile 1 support includes parsing, semantic lint, a closed lexicon,
canonical prompt construction, compile-before-provider ordering, and
fail-closed malformed input handling.

Closed schemas, pure domain logic, prompt preflight, schema lowering,
provider health, ready tokens, process execution, artifact verification,
redaction, canonical JSON, and hashing ship with this boundary.

## Security

The executable enforces CLI input, output, error, argument, resource, time,
artifact, observed-diff, temporary-file, and secret-safety bounds.

Relative host paths normalize once against the CLI invocation directory before
artifact access or provider dispatch. Absolute lexical paths stay preserved.
The provider executable value does not change.

The canary materializer binds the exact challenge nonce in the response
schema. The host still verifies nonce equality after terminal classification
and strict response decoding.

Diagnostics do not write provider output, environment values, prompt bytes,
schema bytes, or filesystem paths.

## Limits

Total Georgecall does not ship:

- Gemini adapter or Google dispatch
- complete Council review coordinator or live review runtime
- Council MCP server or native host plugins
- authoritative event and artifact persistence for Council
- complete Node.js and TypeScript migration or Python removal
- project registry or session-transport work
- automatic credential provisioning or external runtime-state placement
- fixture-aware Grok source-secret scanning
- Graphify vendored skill 0.9.15 to installed package 0.9.32 synchronization
- queue-admission race fix or target-worktree harness telemetry separation
- a broader external dogfood matrix
- npm publication

POSIX and WSL provider execution are the live target boundary. Native Windows
receives hosted build and process-test coverage. The hosted Windows gate does
not run the complete Bats suite. Native Windows live provider canaries are
outside this release.

Read `docs/RESIDUALS.md` and the canonical ledger before you claim support
beyond this boundary.

# Foreman v0.2.9.0

Foreman v0.2.9.0 adds a smaller, executable Council preflight boundary. The new
runtime uses Node.js 24 and TypeScript. It builds as one self-contained ESM
file and does not load workspace TypeScript source at run time.

## Product changes

- Add the `council-preflight` executable.
- Compile the Attempto Controlled English contract before a provider starts.
- Support bounded canaries for Grok, Claude, and Codex.
- Bind each successful canary response to a unique challenge nonce.
- Return typed, secret-safe failures for invalid input, provider failures,
  timeouts, output limits, and unsupported Google dispatch.
- Bound input, output, artifacts, observed diffs, process time, and temporary
  files.
- Resolve relative Council runtime paths once, before provider dispatch.

- The exact-merge knowledge graph covers 401 source files with 2,781 nodes,

Council preserved `quorum_not_met` for the audited bundle because the cold
audit was not bound to a Council ready token. This advisory shadow result is
not a release rejection. Deterministic Foreman release gates remain the merge
authority.

## Scope boundaries

This release does not include Gemini dispatch, npm publication, complete
Council orchestration, or complete Python removal. New executable code follows
the Node.js and TypeScript migration rule.

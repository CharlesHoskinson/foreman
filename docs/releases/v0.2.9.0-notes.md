# v0.2.9.0 release candidate notes

These notes describe the active candidate. They do not claim that the release is complete.

## Product

The candidate adds the `council-preflight` executable. The executable runs on Node.js 24 and is written in TypeScript.

The build produces one self-contained ESM file. The file does not load workspace TypeScript source at runtime.

The executable supports Grok, Claude, and Codex canaries. A Google request returns a static dispatch failure.

## Safety boundary

Council compiles the ACE contract before it starts a provider process. Invalid ACE returns one typed prompt failure.

The runtime bounds input, output, artifacts, observed diffs, timeouts, and temporary files. Public failures do not include runtime secrets.

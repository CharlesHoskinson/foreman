## Recovery and evidence rules

- Record a SHA-256 digest for every untracked file before relocation.
- Record the commit and tree for every tracked deletion.
- Keep removal reversible until the replacement passes deterministic tests and
  a cold audit.
- Do not delete historical evidence only because its claim is stale. Remove it
  from current authority and keep its dated context.
- Rebuild Graphify after tracked removals. Reject a generation that keeps a
  current-authority edge to a deleted source.
- Add the final disposition and evidence link to this log in the same sprint
  that executes the action.

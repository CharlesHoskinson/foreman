## The near-miss worth internalising

`round-ownership-default` reported success with a summary claiming independent
verification. In fact its worktree contained:

```
[[ "$durable_enabled" == "__disabled_for_independent_proof__" ]]
```

A literal that can never match — the refusal branch was dead, so every unowned
dispatch would have proceeded silently. The lane had sabotaged the predicate for
a destructive proof and its turn ended before the restore. **It did not lie**; it
correctly reported the proof unfinished. The hazard is that the leftover
filesystem state looks like completed work in `git status`.

What caught it: the **registered pass baseline** (8) disagreeing with the
observed count (7). That tripwire exists only because the policy layer was
recalibrated this morning — eight packages had shipped `.bats` files registered
in neither policy file.

`skills/foreman/scripts/lane-complete-check.sh` now makes both conditions
mechanical. Run it before every lane commit.

## How to dispatch a grok lane so it actually works

Measured today across five dispatches — see AGENT_TRAPS §7 for the full table.

```bash
cd /root/fm-wt/integrate
FM_LANE_OWNER=arch bash tools/lanectl.sh launch LABEL -- \
  bash skills/foreman/scripts/lane-run.sh RUN LABEL /root/fm-wt/WT -- \
  bash skills/foreman/scripts/grok-multiround.sh /root/fm-specs/SPEC-x.md --max-rounds 3 -- \
  grok -m grok-4.5 --allow Write --allow Edit --output-format plain --cwd /root/fm-wt/WT
```

- **ONE deliverable per dispatch.** Two empty-burst even when both are well
  specified.
- **Inline every fact.** `--prompt-file` is single-turn: a spec the worker must
  READ before it can WRITE cannot succeed at any `--max-rounds`.
- **Write-first names the real source file**, never a notes/sentinel file.
- Keep specs in `/root/fm-specs/`, outside the worktree.
- Diagnosis is the architect's job and is the actual cost. A five-line change
  already specified to the character is cheaper to write than to delegate.

## 2. What went right — with evidence

**The lock defect was measured, not argued.**

| `mkdir` implementation | mutual-exclusion violations / 15 rounds of 8 racers |
|---|---|
| uutils 0.8.0 (system default) | **57** |
| GNU 9.7 | **0** |
| `flock` (ext4 / tmpfs / drvfs) | **0** |

`strace` isolated the mechanism: uutils issues `statx` and never calls
`mkdir(2)`; GNU takes `EEXIST` from the kernel.

**The formal models reproduced real defects.** `eventlog_concurrency`'s
counterexample is `seqHolders: Set(0, 1)` — the exact state measured live, but
derived independently from the code. `audit_gate` reproduced the stale-verdict
hole; `lane_lifecycle` reproduced the background-and-stop attractor at Apalache
depth 12.

**Live verification beat reading, repeatedly.** The council's 33-object
TerminusDB schema was loaded into pinned 12.0.6: it accepted, persisted, and
rejected undeclared fields and invalid enums. When the ingest blocker was later
fixed, re-running gave **5/5**.

**Models found what audits missed.** `lane_lifecycle` surfaced a defect no
reviewer had: the structural fix for failure class #1 holds *only until the
first auto-resume*, because `GATE_CMD`/`REPORT_PATH` are recorded in no event
payload. Confirmed in shipped code at `lane-supervise.sh:343-345`, which logs
the problem and proceeds anyway.

## 4. Standing rules that came out of today

1. **A success predicate binds to an artifact and its content** — never an exit
   code, a substring match, or an agent's own account of its state.
2. **Every checker must be demonstrated to fail** against a known-bad input
   before it is trusted. A check never observed failing is not evidence.
3. **An invariant that holds vacuously is reported as vacuous**, not as a pass.
4. **A result that would change a release decision is corroborated by an
   independent check with a different predicate.** This is the only mechanism
   that caught anything today.
5. **Never build a heredoc inline through `bash -lc`** with prose containing
   backticks or apostrophes. Write to `/tmp` from a file, then
   `tr -d '\r' < /tmp/f > target`.
6. **Read `stopReason` / `cancellationCategory` from the vendor log** — never
   infer why a lane produced nothing. Two causes present identically.
7. **Scope by inventory, not by count.** Three documents carried three
   different numbers for the same fix; all three were wrong.
8. **Two agreeing lanes are not a control.** A third lane with an actual
   control experiment refuted a conclusion two agreeing lanes had reached.

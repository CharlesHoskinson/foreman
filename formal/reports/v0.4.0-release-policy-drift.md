# v0.4.0 release-policy drift review

The v0.4 release changes `gate-eval.sh` so it invokes the compiled release
policy after the existing general gate succeeds. The new check is an additional
fail-closed precondition. It does not change the audit verdict states, freshness
rules, retry bounds, or transitions represented by `audit_gate.qnt`.

The same change passes a canonical evidence path to the compiled policy. It
does not change the receipt states or action transitions represented by
`evidence_contract.qnt`. The TypeScript release-policy and release-admission
tests own the new canonical receipt, registration, and action-specific checks.

The existing Quint models and their expectation rows are therefore unchanged.
This record closes the source-to-model drift review without changing a model
that does not represent the added composed precondition.
